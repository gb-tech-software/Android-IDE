This is a dependency-free static web starter for projects that use browser-native HTML, CSS, and JavaScript without a bundler.

## Getting started

Run the included local development server:

```bash
npm run dev
```

The server uses Python's standard library and serves the project at port 5173. Open `index.html` directly only for simple inspection; use the local server when working with module scripts or browser APIs.

## Project structure

- `index.html` — browser document entry point
- `src/main.js` — application JavaScript
- `styles/main.css` — visual styles
- `package.json` — the dependency-free development command
- `.gitignore` — generated and local files excluded from Git

Use Android IDE's editor for HTML, CSS, and JavaScript, the terminal for project commands, and the Android IDE browser for browser-based output when available.
