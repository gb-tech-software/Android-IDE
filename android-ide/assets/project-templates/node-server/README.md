## Getting started

```bash
npm install
npm start
```

Set `PORT` to change the listening port. Use the development command while editing:

```bash
npm run dev
```

## Project structure

- `src/server.js` — HTTP server entry point
- `package.json` — scripts and server metadata
- `.gitignore` — generated and local files excluded from Git
