This starter uses Express with ESM, JSON request middleware, a root route, and a health endpoint.

## Getting started

```bash
npm install
npm start
```

Use the development command while editing:

```bash
npm run dev
```

The server listens on `PORT` when provided and defaults to port 3000.

## Project structure

- `src/server.js` — Express application and server entry point
- `package.json` — Express dependency and lifecycle scripts
- `.gitignore` — generated and local files excluded from Git

Add routes, validation, services, integrations, and deployment configuration as the project develops. Use the Android IDE browser to inspect browser-accessible output.
