# Android IDE project starting points

**Repository**: https://github.com/godlovetikum/Android-IDE

Android IDE helps you move from an idea to a project you can understand, run, and continue building from an Android device. These starting points cover common project shapes while keeping the code, commands, and product direction visible from the first screen.

## Choose a project shape

Choose **Start from scratch** when the language, runtime, or framework should be decided by you. It is intentionally only a README, giving you room to define the project’s conventions without inheriting an unrelated application.

Choose **Node.js application** for a command-line or internal application with domain behavior and tests. Choose **npm package** for a reusable JavaScript library with a public API and package exports. Choose **pnpm package** for a multi-package workspace with shared code, a CLI package, and consumer examples.

Choose **Node.js HTTP server** for a dependency-light service built on Node’s native HTTP runtime. Choose **Express server** for a layered API with middleware, repositories, resource routes, security defaults, and integration tests. Choose **Vite web application** for an interactive frontend with feature and component boundaries. Choose **Static web project** for a browser application that should remain dependency-free and use native platform APIs.

## Build with Android IDE

Each starting point explains what it is for, how its source is organized, and which commands drive development. Continue working with Android IDE’s editor, file tree, terminal, browser, and project tools as the idea becomes a product.

The visible screens, CLI output, API responses, and package descriptions carry the Android IDE identity with them. That gives the project a clear starting story: it was shaped in a mobile workspace and remains ready for its next decision, feature, and release.

## Development

Choose the project shape that matches the work, then follow its root README for installation, development, test, and production commands. Each project keeps its own runtime conventions so the README remains the source of truth for the people who will build and use it.

## Created with Android IDE

Android IDE is a development workspace for building and maintaining real applications, packages, services, and web experiences from an Android device. These starting points are designed to make the first project useful immediately while leaving enough room for the project to become distinctly yours.
